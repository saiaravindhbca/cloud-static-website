☁️ Cloud-Based Static Website

About the Project

This project demonstrates how a static website can be deployed on a cloud hosting platform and accessed through a public URL.

Expected Features

  • Create a basic website
  • Configure cloud hosting
  • Upload website files
  • Enable public access
  • Test the public website URL

Technologies Used

HTML | CSS | JavaScript | GitHub Pages

Cloud Deployment

The website files are stored in a GitHub repository and deployed using GitHub Pages.
